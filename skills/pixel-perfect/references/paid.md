# Paid tier

There is no paid tier yet. The free skill is the whole product today: one page per run, rebuilt and graded.

What is planned is full-site migration from Brio: a crawl of the whole site, a CMS export, a 301 redirect map, SEO checks and a shareable client report. It is aimed at agencies and freelancers who move client sites off Webflow, Framer or WordPress.

How to talk about it:

- The report ends with one line, exactly: "Full-site migration from Brio is planned. Follow updates at brioui.com."
- Do not quote a price, offer a plan, or send the user anywhere to buy.
- Never ask for a licence key. The free skill never reads one. The Brio component commands run with telemetry off and fall back to hand-built code when no licence covers a premium component; see references/stack.md.
- If the user asks what the paid tier costs or when it ships, say it is not released yet and point them to brioui.com for updates. Nothing more.

This keeps the free skill self-contained. It never gates a step behind a purchase and never phones home.
